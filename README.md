# MantraInsights

# 🛒 Smart Retail Analytics & Inventory Management System

> A smart e-commerce platform that combines online shopping, inventory management, workflow automation, customer support, order tracking, and business analytics into one integrated system.

---

## 📌 Project Overview

The **Smart Retail Analytics & Inventory Management System** is an e-commerce web application designed to provide a seamless shopping experience while helping businesses understand product performance, sales trends, and retail operations through analytics.

The system combines:

- 🛍️ E-commerce product browsing
- 🛒 Shopping cart
- 💳 Buy Now / Checkout
- 📦 Order tracking
- 👤 Customer information management
- 📊 Power BI analytics
- 🤖 n8n-powered chatbot
- ⚡ n8n workflow automation
- 📋 Google Sheets integration
- 🗄️ Backend API
- 📱 Responsive mobile-friendly interface
- 🎨 Glassmorphism UI

The project is designed to demonstrate how **e-commerce, automation, data analytics, and intelligent customer interaction** can work together in a single platform.

---

# 🎯 Objectives

The main objectives of this project are:

1. To develop a modern and responsive e-commerce website.
2. To provide customers with an easy way to browse products.
3. To organize products into multiple categories.
4. To provide detailed product information.
5. To implement Add to Cart and Buy Now functionality.
6. To collect customer and order information during checkout.
7. To automate order data storage using n8n and Google Sheets.
8. To provide order tracking functionality.
9. To integrate an intelligent chatbot using n8n.
10. To analyze retail data using Microsoft Power BI.
11. To provide useful business insights through interactive dashboards.
12. To create a mobile-friendly and user-friendly interface.

---

# 💡 Key Features

## 🛍️ Product Catalog

The application provides a product catalog based on the retail dataset.

Products are organized into three major categories:

- 🪑 Furniture
- 📎 Office Supplies
- 💻 Technology

Each product can display information such as:

- Product ID
- Product Name
- Category
- Sub-Category
- Sales information
- Product details
